# Scuffle's Automated Metal Farm Collection
This mod automates the collection of items from metal farms once they've fully "grown".

## Requirements
* Subnautica 2 UE4SS on [NexusMods](https://www.nexusmods.com/subnautica2/mods/36) or [GitHub](https://github.com/Subnautica2Modding/Subnautica2-UE4SS)
* Mod Settings for Subnautica 2 on [NexusMods](https://www.nexusmods.com/subnautica2/mods/20) or [GitHub](https://github.com/Just-Chaldea/SN2-ModSettings)
